# Asset Sources and Licensing

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](LICENSE-SOURCES.vi.md)

All release showcase images are project-generated; no arbitrary web photograph is required.

## AI-generated photorealistic assets

The six JPEG files under `examples/realistic/` were generated specifically for this project using OpenAI image generation and resized to 1024×768. They are synthetic benchmark images, not downloaded photographs.

## Programmatically generated assets

The remaining benchmark PNG files were generated specifically for this repository from fictional controlled data.

## Provenance controls

`ASSET_MANIFEST.json` records the SHA-256 digest and generation class of release assets. Future third-party assets must record source URL, author, license, modification history and redistribution basis before merge.
