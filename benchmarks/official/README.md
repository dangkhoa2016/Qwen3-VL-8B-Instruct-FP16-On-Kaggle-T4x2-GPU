# Official Benchmark Artifacts

This directory is reserved for reviewed artifacts from the final public Kaggle production-showcase execution.

Development-session measurements belong in `docs/BENCHMARKS.md` with an explicit development-evidence label. Do not copy local `results/` here automatically.

Before promoting an artifact, verify the Kaggle notebook/version, commit SHA, model attachment/revision, T4 x2 runtime identity, FP16/no-offload gates, evidence hashes, and reviewer acceptance.
