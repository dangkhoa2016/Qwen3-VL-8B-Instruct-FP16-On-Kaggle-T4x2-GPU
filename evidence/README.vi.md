# Evidence Workspace

> 🌐 Language / Ngôn ngữ: [English](README.md) | **Tiếng Việt**

Thư mục này mô tả evidence contract. Development/session output nằm trong `results/` và được Git ignore. `benchmarks/official/` là source-controlled index cho official evidence; executed Kaggle notebook/version cùng GitHub Release assets tương ứng mới là immutable runtime evidence authority.

Official evidence phải được review theo đúng exact frozen source commit. CI/static verification chỉ là supporting evidence, không phải evidence inference model thật, và publication sau run không được rewrite source SHA đã được chứng minh.
