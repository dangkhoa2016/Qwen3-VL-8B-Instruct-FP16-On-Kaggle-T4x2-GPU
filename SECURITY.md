# Security Policy

## Supported versions

Security fixes currently target the latest development branch and the latest tagged release once releases exist.

## Reporting a vulnerability

Please do not disclose secrets, private data, or exploitable details in a public issue. Contact the repository owner privately through the contact channel published on the GitHub profile/repository. Include a concise reproduction, affected version/commit and impact assessment.

This repository is a Kaggle reference implementation. Public tunnel exposure is optional and disabled by default; see `docs/SECURITY.md` for the runtime security model.
