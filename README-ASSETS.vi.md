# Benchmark Assets

> 🌐 Language / Ngôn ngữ: [English](README-ASSETS.md) | **Tiếng Việt**

Bộ release assets được thiết kế cho multimodal review reproducible, không phải random visual browsing.

- controlled PNG kiểm tra spatial relation, document, table và chart với ground truth xác định;
- sáu JPEG photorealistic kiểm tra OCR, extraction và scene understanding thực tế hơn;
- `ASSET_MANIFEST.json` lưu SHA-256 và generation class;
- `ground_truth/cases.json` định nghĩa prompt, schema và expected facts;
- `PREVIEW-CONTACT-SHEET.png` cho reviewer overview.

Xem [docs/asset-provenance.vi.md](docs/asset-provenance.vi.md) và [LICENSE-SOURCES.vi.md](LICENSE-SOURCES.vi.md).
