# Engineering Overview

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](engineering-overview.vi.md)

The repository turns a successful model load into a reviewable service rather than hiding everything inside one notebook cell.

The engineering priorities are: strict FP16 identity, explicit two-T4 placement, no weight offload, a single long-lived model instance, specialized REST endpoints, schema-validated extraction, local-first security, reproducible assets, and evidence that distinguishes transport success from semantic quality.

The acceptance notebook remains the baseline qualification authority; this repository focuses on reusable serving and deeper multimodal demonstrations.
