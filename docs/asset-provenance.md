# Asset Provenance

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](asset-provenance.vi.md)

The release catalog is self-contained and does not depend on random Internet photographs.

- `examples/realistic/`: six AI-generated photorealistic JPEGs created specifically for this project and resized to 1024×768.
- other `examples/` directories: programmatically generated controlled PNGs using fictional benchmark data.
- `ASSET_MANIFEST.json`: SHA-256 and generation class.
- `ground_truth/cases.json`: prompt, expected facts and structured schemas.

Fictional organizations and identifiers are used to avoid presenting synthetic benchmark documents as real commercial records.
