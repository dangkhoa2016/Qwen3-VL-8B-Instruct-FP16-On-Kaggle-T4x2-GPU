# Support

For reproducibility questions, runtime issues or documentation gaps, open a GitHub issue using the closest template. Include the commit SHA, Kaggle accelerator, Python/Transformers versions, endpoint or notebook cell involved, and a minimal reproduction.

Security-sensitive reports should follow [SECURITY.md](SECURITY.md) instead of a public issue.
