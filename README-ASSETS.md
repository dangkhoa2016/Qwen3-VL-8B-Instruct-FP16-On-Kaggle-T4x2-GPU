# Benchmark Assets

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](README-ASSETS.vi.md)

The release asset set is designed for reproducible multimodal review rather than random visual browsing.

- controlled PNGs exercise spatial relations, documents, tables and charts with deterministic ground truth;
- six photorealistic JPEGs exercise realistic OCR, extraction and scene understanding;
- `ASSET_MANIFEST.json` records SHA-256 and generation class;
- `ground_truth/cases.json` defines prompts, schemas and expected facts;
- `PREVIEW-CONTACT-SHEET.png` provides a reviewer overview.

See [docs/asset-provenance.md](docs/asset-provenance.md) and [LICENSE-SOURCES.md](LICENSE-SOURCES.md).
